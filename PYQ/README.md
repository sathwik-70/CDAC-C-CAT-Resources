## ⏱️ Exam Strategy & Time Management

- **Time Allocation:** 60 Minutes per Section (50 Questions each). That is **72 seconds** per question.
- **Marking Scheme:** **+3** for every correct answer, **-1** for every incorrect answer.
- **Round-based Attempt Strategy:**
  - **Round 1 (First 25-30 mins):** Solve all direct, memory-based, and easy questions (e.g., Computer Fundamentals, English, straightforward Digital logic / OS definitions).
  - **Round 2 (Next 20-25 mins):** Solve moderate numericals (Aptitude, C pointer dry-runs, CPU scheduling, Cache mapping).
  - **Round 3 (Last 5-10 mins):** Review flagged questions. **Avoid blind guessing** due to negative marking.
