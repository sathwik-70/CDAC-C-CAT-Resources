# 🔸 Section B: Coding, OOPS, DSA & Operating Systems

This section is **mandatory for Group B & C courses** (such as PG-DAC, PG-DMC, PG-DBDA, PG-DESD, etc.). It consists of 50 questions to be solved in 60 minutes. This section requires strong logical understanding, syntax knowledge, and memory of fundamentals.

---

## 📋 Syllabus Breakdown & Study Material

### 1. C Programming
*   **Key Topics:** Pointers (Single & Multidimensional), Pointer Arithmetic, Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`), Storage Classes (`auto`, `extern`, `static`, `register`), Preprocessor Directives, Bitwise Operators, Structure & Union.
*   **Recommended Book:** *Let Us C* by Yashavant Kanetkar / *C: The Complete Reference* by Herbert Schildt.
*   **Free Open-Source Resources:**
    *   [Neso Academy - C Programming Playlist](https://www.youtube.com/playlist?list=PLBlnK6fEyqRggZZgYpPMUxdY1CYkZtARR): Very clear and beginner-friendly tutorials.
    *   [GeeksforGeeks - C Programming](https://www.geeksforgeeks.org/c-programming-language/): Comprehensive guide.
    *   [Sanfoundry - C Programming MCQs](https://www.sanfoundry.com/1000-c-programming-questions-answers/): Excellent for practicing output-prediction and error-detection questions.
*   **🎥 Quick-Prep Playlists & Tools:**

## ⚡ Strategy Tips for Section B
*   **Pointer Math:** At least 5-8 questions are based on pointer offsets, pointer arrays, and dereferencing (`ptr++`, `*ptr++`, `++*ptr`). Be extremely confident in pointer arithmetic.
*   **Complexity Cheat Sheet:** Memorize the worst, average, and best-case time complexities of all sorting and searching algorithms. (e.g., QuickSort, MergeSort, HeapSort).
*   **CPU Scheduling and Banker's Algorithm:** Expect numerical questions on Turnaround Time (TAT) / Waiting Time (WT) calculations, and finding safe states. Practice these on paper.
*   **Mind the Negative Marking:** Tricky code snippets are prone to silly mistakes. Double check your dry-runs before marking answers.
